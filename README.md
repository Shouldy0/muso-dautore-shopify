# Muso d’Autore — tema Shopify premium

Tema Shopify Online Store 2.0 per caricature personalizzate di animali.

## Installazione

1. Crea lo ZIP dalla cartella del tema, mantenendo `assets`, `config`, `layout`, `locales`, `sections` e `templates` nella radice.
2. In Shopify vai su **Negozio online → Temi → Importa tema → Carica file ZIP**.
3. Crea il prodotto principale e collegalo al pulsante della hero dall’editor del tema.

Gli ordini digitali devono essere configurati come prodotti senza spedizione. Le varianti con stampa A4/A3 devono richiedere la spedizione.
